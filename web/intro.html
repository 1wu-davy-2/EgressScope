能力

六个环节，组成一条可复核的证据链

不读 Agent 的私有会话文件，只看真实外发：谁、发往哪里、带走了什么、证据是否完整。

HTTPS 外发可见性

还原经过本地代理的请求与响应，并为每条流量标注可见性等级。

TLS 1.2 / 1.3 · HTTP/1.1 · HTTP/2

进程级归因

把连接定位到 PID、父进程链与脱敏命令行，降低 PID 复用误判。

port → PID → parent chain

AI 与敏感数据识别

识别 AI 端点、模型与 token 用量，并命中密钥、证件号、银行卡与源码风险。

ai_saas / ai_local · DLP rules

正文加密保存，摘要逐条哈希链接，列表与导出默认脱敏。

AES-256-GCM · SHA-256 chain

边界

能看见什么，不能看见什么

用户态审计有明确边界。我们把限制写在前面，而不是把“代理运行中”说成“全部可见”。

在配合路径上可以看见
  • 经过本地代理的 HTTPS 请求、响应与五级可见性
  • 发起进程、父链、脱敏命令行与创建时间
  • AI 端点、模型、token 与敏感数据风险信号
  • 直连、QUIC 与 DNS 目标元数据（仅候选）
不承诺、也看不到
  • 证书固定、mTLS 与应用层端到端加密
  • QUIC / HTTP3 的内容级解析
  • 绕过代理的直连内容
  • Windows 服务 / SYSTEM 会话的完整归因

快速开始

根证书、系统代理与风险阻断都需要你显式确认；采集与观察能力默认开启。

1

安装并启动

运行 Windows 安装器或便携版。代理监听 127.0.0.1:8899，审计台仅回环访问。

2

信任本地 CA

在控制台一键安装到当前用户；私钥不出本机，可随时移除。

3

选择流量入口

开启系统代理（默认勾选断网保护），或只给目标 Agent 注入环境变量。

常见问题

它适合你的场景吗？

先看能力边界与使用前提。安装、更新、托盘与测试状态等技术问题在专门文档中。

查看技术问答
01关机或崩溃后，系统代理会不会让本机断网？
v0.4.0 会关机恢复、启动校正，并可用看门狗或 --restore-proxy 恢复。直接拔电源或强制结束进程时，恢复发生在下次登录后。
02它是杀毒软件或 EDR 吗？
不是。它只做外发可见性、归因、策略与证据留存；风险分是启发式信号，需要人工复核。
03能看见所有加密流量吗？
不能。证书固定、mTLS、端到端加密与绕过代理的直连内容不可见；QUIC 只记录候选元数据。检测不等于拦截。
04数据会上云吗？需要管理员权限吗？
不上云，证据保存在本机并使用 AES-256-GCM 加密。Windows 安装器与 CA、系统代理、自启都按当前用户运行，不需要管理员。
05支持哪些系统？
Windows 10 / 11 x64 与 ARM64；x64 有安装器、自动更新与托盘，ARM64 的 Tk / 托盘未实机验收。macOS 与 Linux 提供审计引擎和 Web 审计台，代理与 CA 需手动配置。
06可以审计别人的设备吗？
只限你拥有或已获得明确书面授权的设备。未知样本请在隔离虚拟机或快照中分析，结束后移除 CA。
