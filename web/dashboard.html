覆盖范围

一套诚实的观测边界，比一个“全部可见”的承诺更有价值。以下内容根据本机运行状态实时生成。

在用户同意下，看见可代理的明文路径。

EgressScope 不尝试攻破应用安全边界。它通过明确的本地代理与受信 CA，在应用愿意配合的范围内还原请求，再以进程归因和内容策略补上上下文。

本地处理 · 显式授权
能够看到
  • 系统代理或环境变量代理生效后的 HTTP / HTTPS 元数据与可解密正文
  • 应用主动信任本地 CA、未启用证书固定的 TLS 1.2 / 1.3 流量
  • 请求与响应正文（不超过配置上限，流式响应只保留元数据）
  • 基于本机 TCP 表的客户端进程 PID、父进程链与脱敏命令行
  • AI 端点分类、模型名、密钥 / PII / 代码 / 文件外发等风险信号
  • 近期外发进程的打开文件句柄抽样（Beta）与 Canary 诱饵触发
无法看到 / 不承诺
  • 未经过本地代理的直连流量，以及忽略系统代理的应用
  • 忽视 / 固定本地 CA 的应用、mTLS、双向证书校验
  • QUIC / HTTP3、非 HTTP 协议，以及应用层端到端加密内容
  • 加密后的内容本体：没有密钥时只能看到连接元数据
  • Windows 服务 / SYSTEM 会话进程的完整网络归因
  • 完整文件读取历史；句柄抽样不能证明读取已经发生

说明：系统代理只改变遵循 WinINet / 系统设置的进程；对单个 Agent 更可控的方式是使用环境变量或未来路线中的 WFP 透明重定向。透明重定向不解决 TLS 固定或 E2EE。

策略与设置

所有策略都会热更新并写入本地配置，无需重启代理或程序；直接编辑配置文件也会在 2 秒内被采纳。涉及系统代理和根证书的变更只从桌面控制台发起，Web 审计台不代你做出系统级授权。

采集与处置

即时生效
启用流量采集
关闭后仍保持代理进程运行，但不再将新流量写入证据库。已产生的证据不受影响。
风险阻断 主动
达到阈值的请求会被本地代理直接返回 403。默认关闭；开启前请确认不会中断关键工作流。
阻断阈值
分数由规则信号累加，85 及以上为严重。阈值越低保守性越强，也越容易误伤。
85
保存原始正文
仅对 AI 流量或风险分 ≥ 25 的请求加密保存，单请求上限 2 MB。关闭后只保留脱敏预览与元数据。
证据保留
超过保留期的流量、发现与文件事件会在启动或清理时删除。

文件触达（Beta）

不读取文件内容
打开句柄抽样
只对近期外发或活跃 TCP 连接进程采样，记录敏感路径元数据并做 120 秒去重。不是完整读取审计。
Canary 诱饵文件
在 Documents 下写入含虚构凭据的诱饵文件，用来观察异常进程是否触达。文件内容为假数据，启用会留下可见文件。
抽样间隔
两次句柄扫描之间的间隔（秒）。更频繁会消耗更多 CPU 与句柄枚举时间。
4s
网络旁路观测（Beta）
只读取本机连接表与 Windows DNS 解析缓存，标记直连、QUIC/UDP 443 与 DNS 目标。不做透明重定向、不抓包，也无法解密 QUIC 或 E2EE 内容；DNS 只记录目标，不记录查询内容。关闭流量采集时会自动暂停。

上行链路

热更新 · 代理自动重连
继承系统原代理
启动或热更新时若系统代理指向本机回环 HTTP 代理（例如 Clash 的 127.0.0.1:7890），自动串联它，避免接管后断网。PAC 与非回环代理不会被继承。
指定上游代理
可选，覆盖自动继承。仅支持无认证的 HTTP/HTTPS 代理地址；本机审计仍会解密可见的 TLS 正文，再经上游隧道发出。

证据与隐私

原始请求正文使用 AES-GCM 加密存放，主密钥由当前 Windows 用户的 DPAPI 保护。导出的 JSONL 只含脱敏预览、元数据与发现，不包含原始正文。

快速说明

需要查看某个请求的完整正文？在流量详情中选择“解密并显示原文”。解密只发生在当前浏览器会话内，服务端不会把原始正文写回数据库或导出文件。

怀疑设备已被未知恶意软件控制时，不要在日常设备上安装受信 CA。请在一台隔离的虚拟机或实验设备中分析样本，避免代理信任边界被滥用。
